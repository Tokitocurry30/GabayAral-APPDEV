Copy Subjects

Copy selected Subject Offerings from one Section to another.

Subject Offerings
This tool copies selected Subject definitions into separate Subject Offerings for a destination Section. Teacher assignment information is presented only as a suggestion for review.
Copying does not duplicate announcements, activities, Student enrollments, submissions, grades or Guardian acknowledgments. Existing destination Offerings are skipped.

Select Source Section

Select the existing Section whose active Subject Offerings you want to copy.

Only active Subject Offerings from the selected source Section are available for copying.

Select Destination Section

Choose the Section that will receive the selected Subject Offerings.

The source and destination must be different Sections within the same authorized School workspace.

Select Subjects to Copy

Select which active Subject Offerings from the source Section should be prepared for the destination.

Available Subject Offerings
A subject that already has an Offering in the destination Section will be unavailable for copying. Review or restore the existing Offering instead.

Review Teacher Suggestions

Review available Teacher information from the source Offerings. You may retain it as a suggestion for the destination assignment process.

Retaining a suggestion does not create an active Teacher Assignment, send an invitation or transfer an existing assignment. Teacher assignment remains a separate authorized workflow.

Review Copy Operation

Check the source, destination, selected subjects and Teacher suggestions before completing the demonstration.
